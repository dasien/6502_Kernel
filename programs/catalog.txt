# programs/catalog.txt - everything that can go on an MFC disk.
#
# One section per item. This file says what EXISTS; which of it lands on a given
# disk is a separate question (see the disk target, and profiles when they arrive).
# It is the single source of truth: the build reads it to stage the disk bundle and
# to generate the diskmap mkdisk consumes, so adding a program is one entry here
# rather than three edits in three files that fail silently if you miss one.
#
#   [name]       the handle used to refer to this item
#   dir   =      where its files live, relative to the repo root
#   build =      script that produces them; OMIT for committed content
#   desc  =      one line, for humans
#
# Files are declared by what they ARE, because the difference matters:
#
#   program = the .PRG. At most one -- it is what makes an entry launchable.
#   data    = read or written by the program at run time. Never separable from it.
#   doc     = for a human to read with TYPE. Droppable if a disk is tight.
#
# Each takes "SOURCE -> DISKPATH", SOURCE relative to dir. All three are repeatable.
